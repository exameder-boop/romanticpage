# Romantic Page

Aplicación web interactiva construida con React, TypeScript y Vite para ofrecer una experiencia romántica paso a paso.

## Desarrollo

```bash
npm install
npm run dev
```

## Despliegue en Netlify

Netlify puede desplegar este proyecto con estas configuraciones:

- Build command: `npm run build`
- Publish directory: `dist`

El repositorio ya incluye una configuración de fallback para rutas SPA.
